# Atharva Homes Launch

Build the Atharva Homes website (construction & interior design company based in New Delhi). Implement the shared layout with the sticky navbar and footer, data files in lib/services.ts, lib/team.ts, and lib/site.ts, and the complete Home page (hero, introduction, 6-service grid, why choose us, founder intro, team intro, project gallery, 4-step process, and CTA). Follow warm architectural minimalism with the defined palette (#FFFFFF, #F5F0E8, #FAF8F4, #E7DCCB, #81786D, #252321), Playfair Display headings, Inter body, and subtle Framer Motion transitions. Follow the strict image rules: reference exact /images/*.png paths, place the exact full image-generation prompts in alt attributes, use no external or generated images, ensure containers hold layout elegantly when images are missing, and keep founder/team/contact details as placeholders without fabricating information.
